# lawyer-site

Static HTML site for Krunoslav Aljinović, Attorney at Law (Split, Croatia).

## Local development

```bash
npm run dev
```

Opens at http://localhost:3000

Alternatively with Python:

```bash
python -m http.server 8080
```

## Deploy

Hosted on GitHub Pages: https://pinjamar.github.io/lawyer-site/

## Structure

```
index.html      # HR (Croatian) — main page
en/index.html   # EN (English)
fr/index.html   # FR (French)
thanks/         # Form submission thank-you page
404.html        # Custom 404
robots.txt
sitemap.xml
```
